# Hirstel-Hugel - Site Web Professionnel

Site vitrine professionnel pour l'entreprise de serrurerie, menuiserie et aluminium Hirstel-Hugel à Strasbourg.

## 🎨 Caractéristiques

### Design
- **Hero fullscreen** avec fond rouge premium et image d'arrière-plan
- **Design responsive** mobile-first (320px à 1920px+)
- **Animations subtiles** et micro-interactions
- **Typographie Inter** pour une lecture optimale
- **Palette de couleurs** professionnelle (rouge #8B2E2B + niveaux de gris)

### Sections
1. **Navigation sticky** - Logo + téléphone
2. **Hero** - Titre majuscule + CTA + badges de confiance
3. **Services** - Grille 4 colonnes avec hover effects
4. **Pourquoi nous choisir** - Features + statistiques
5. **CTA Banner** - Appel à l'action central
6. **Footer** - Complet avec liens et contact

### Optimisations
- Meta tags SEO optimisés
- Smooth scroll
- Images optimisées (à ajouter)
- Performance CSS optimisée
- Transitions fluides

## 📸 Image d'arrière-plan

Pour le hero, placez une image professionnelle nommée `hero-bg.jpg` dans ce dossier.

**Recommandations :**
- Format: JPG optimisé
- Dimensions: 1920x1080px minimum
- Poids: < 500KB
- Sujet: Atelier, artisan au travail, métal, outils

**Sources gratuites :**
- Unsplash: https://unsplash.com/s/photos/metal-work
- Pexels: https://www.pexels.com/search/craftsman/
- Pixabay: https://pixabay.com/images/search/workshop/
