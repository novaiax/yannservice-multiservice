## 🚀 Installation

### 1. Fichiers nécessaires
```
page3-full-premium.html
css/page3-premium.css
js/page3-premium.js
```

### 2. Personnalisation

#### a. Modifier les informations du salon
Dans `page3-full-premium.html`, remplacer :
- `Salon Éclat` → Votre nom de salon
- `Paris 1er` → Votre ville
- `+33123456789` → Votre numéro de téléphone
- `15 Rue de la République, 75001 Paris` → Votre adresse

#### b. Modifier les prix
Ajuster les prix dans la section **Services** et **Packs Premium**

#### c. Modifier les produits
Personnaliser la liste des produits selon les marques utilisées

#### d. Remplacer les images
Remplacer les URL Unsplash par vos propres photos :
- Photos avant/après de qualité
- Photos de l'intérieur du salon
- Photos de l'équipe

### 3. Lancement
1. Uploader les 3 fichiers sur votre hébergement
2. Ouvrir `page3-full-premium.html` dans un navigateur
3. Tester sur mobile ET desktop
4. Vérifier que tous les numéros de téléphone fonctionnent

## 💡 Conseils d'Optimisation

### Pour maximiser les appels :
1. **Tester les horaires d'ouverture** : afficher "Ouvert maintenant" en temps réel
2. **A/B tester** les textes des CTA ("Appeler" vs "Appeler maintenant" vs "Devis rapide")
3. **Ajouter l'urgence** : "3 créneaux disponibles aujourd'hui"
4. **Photos réelles** : vos vrais clients (avec autorisation)
5. **Témoignages vidéo** : courts (15-30s)
6. **Offre d'appel** : "Première consultation téléphonique offerte"

### Pour améliorer le SEO local :
- Ajouter le schema.org LocalBusiness
- Optimiser meta description
- Ajouter les horaires au format structuré
- Intégrer Google My Business
